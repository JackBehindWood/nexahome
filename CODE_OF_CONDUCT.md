# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies to every space where the project is discussed: issues, pull requests, reviews and comments. Be kind, assume good faith, and keep criticism about the work.

## Reporting

Report behaviour that breaks the code of conduct privately, so nobody is exposed in public: use "Report a vulnerability" in this repository's Security tab (the route in [SECURITY.md](SECURITY.md)) and start the report with "Conduct report". There is no email address. The route exists for vulnerabilities, so it is the only private one this project has; it is used here for the same reason.

## Enforcement

This is a solo hobby project, so the maintainer decides, without a promised response time. The consequences are the ones the Covenant describes: a correction, a warning, a temporary ban or a permanent ban.
